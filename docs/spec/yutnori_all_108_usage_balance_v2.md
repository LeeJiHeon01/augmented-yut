# 증강 윷놀이 — 전체 108개 발동 횟수 밸런스 조정안

> 사용자 요청: **패시브만이 아니라 전체 108개**(패시브 46, 액티브 53, 대혼란 증강 9)의 사용/발동 횟수를 **1~3회**로 설정한다. 별개인 자동 대혼란 이벤트 E1~E8은 이 표의 대상이 아니다.

## 적용 원칙

- 표의 횟수는 **게임당 해당 증강의 최대 성공 발동 횟수**다. 교체 후 같은 증강을 다시 얻더라도 한 경기에서 이미 사용한 횟수를 초기화하지 않는 방식을 권장한다(중복 획득 불가 규칙과 별도로 회귀 테스트).
- **패시브**는 조건 충족만으로 차감하지 않고 실제로 효과가 적용되었을 때 1회 차감한다. 확률 효과도 성공 시 차감한다. 단 확률 방어형은 방어 판정을 시도할 때 차감하는 방식을 권장하며, 아래 표에서 관련 예외를 표시한다.
- **액티브**는 서버가 대상·차례·조건을 검증해 실제 효과가 실행된 경우 1회 차감한다. 유효하지 않은 사용 요청은 차감하지 않는다.
- **대혼란 증강(9개)**은 일회성 전역 효과가 크므로 **각 1회**로 설정한다. 자동 발동형 증강이라면 실제 발동 시 1회 차감하고 이후 다시 발동하지 않는다. **자동 이벤트 E1~E8의 4라운드 주기는 수정하지 않는다.**
- “2턴 동안”, “다음 턴까지” 등의 **지속 기간은 사용 횟수가 아니다.** 한 번 발동해서 지속되는 동안의 세부 효과는 별도 차감하지 않는다.
- 기존 효과에 **원래 게임당/말당 1~2회 제한이 있다면 본 표의 게임당 횟수로 통일**하되, 말당 제한처럼 별개의 조건은 충돌 여부를 테스트하고 사용자 판단이 필요한 경우 보고한다.
- 발동 횟수 0이 되면 패시브는 더 이상 효과가 생기지 않고, 액티브는 소진 상태로 표시한다. 추첨 확률·등급 비율·선택/교체 주기·원래 능력 설명은 변경하지 않는다.
- **주의:** 아래 수치는 플레이테스트 전 1차 제안이며 사용자 승인 전에는 적용하지 않는다.

## 구현 확인 사항

- 총 108개 누락 없이 적용: **1회 52개 / 2회 31개 / 3회 25개**.
- 패시브 보유 상태에서도 남은 발동 횟수를 서버에서 유지·검증하고, 0회가 되면 효과 적용을 차단한다.
- 남은 횟수는 UI에 표시하되 **기존 PNG 디자인의 임의 변경은 금지**한다. 새 시각 표현이 필요하다면 먼저 사용자에게 질문한다.
- 확률형 실패·무효 사용·동시 발동·업기 그룹·재접속·교체·턴 넘김·대혼란 중첩·타임아웃에 대한 자동 테스트를 추가한다.
- 활성 상태의 지속형 패시브(예: 지름길 독점, 안전지대)는 “무엇을 발동 1회로 셀지” 기술적으로 모호하다. **매 유효 행동/방어 1건을 1회로 센다는 권장안**을 따르되, 효과 범위가 변하면 구현 전 보고한다.
- 팀 증강 `C-G1`, `C-P2`는 목록에 포함하지만 기존처럼 비활성인 경우 사용·추첨 활성화는 별도 승인 후 진행한다.

## Claude Code 전달 요지

108개 전부를 대상으로 한다. 패시브 46개만 고치는 것이 아니다. 각 ID별 상기 최대 횟수에 따라 서버 상태·사용 로직·UI 잔여 횟수·테스트를 수정한다. 규칙 자체를 임의로 바꾸지 않는다. 적용 전 위 제안안을 사용자에게 확인받는다.
