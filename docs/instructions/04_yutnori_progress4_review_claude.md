## 1. 최우선: 사용자 결정 필요 8개 처리

`docs/augment_review.md`의 8개 선택지를 **원문 그대로** 사용자에게 제시하고 결정을 받아라. 특히 원안과 달라진 4개는 우선 검토한다.

- `O-S6`: 잡히면 즉시 추가 던지기 → 다음 자기 차례로 변경됨.
- `C-S12`: 상대가 이동을 결정 → 무작위 이동으로 변경됨.
- `C-G11`: 소유권/사용 횟수 강탈 계열의 원안 대비 구현 차이 확인.
- `C-P4`: 판 위 말 소유권 교환 → 위치 교환으로 변경됨.

결정 전에는 해당 효과의 의미를 임의 변경하지 말 것. 나머지 '해석 37개'도 원문·구현·테스트·게임 영향도를 비교하고, 결과에 큰 영향을 주는 경우 우선 사용자 승인을 요청할 것.

## 2. E2 임시 동맹 규칙 확정 전 비활성 유지

2인·3인·4인에서 동맹을 어떻게 구성할지, 잡기/승리/점수/동맹 해제 처리 방식을 별도로 제시하라. E2를 무단 활성화하지 말 것. 팀 관련 증강 C-G1·C-P2도 기존 비활성 방침 유지.

## 3. 엔진 검증 강화

- 증강 106개에 대한 ID별 테스트가 있다는 보고와 별개로, **효과별 입력·상태 변경·횟수 소진·발동 안 되는 조건**까지 검증되었는지 커버리지 점검.
- 2~4인별 정상 종료뿐 아니라 지름길·업기·잡기·골인과 다중 증강·지속 이벤트 충돌, 시간 초과·재접속 등 경계 상황 테스트.
- 확률 추첨 40/40/20, 등급 내 대혼란 총합 5%, 보유/제외 카드 재정규화, 리롤 중복 제거에 대한 통계/불변식 테스트.
- 4라운드 이벤트와 같은 시점 증강 선택이 겹치면 **이벤트 먼저, 선택 나중**인지 확인.
- 2~4인 실제 브라우저 참여자끼리의 E2 외 7개 이벤트 동기화·재접속 시 상태 복원·상대 비공개 후보 미노출 확인.

## 4. 문서 최신화
