## 4. 테스트 커버리지

- 자동 테스트: shared 256 · server 13 · client 14 = **283개 통과**
- ID를 직접 다루는 테스트가 없는 증강: 없음
- 충돌 조합 테스트(`collisions.test.ts`): 강제 던지기+확률 패시브, 방어+증강 이동, 업힌 말+자리 교환, 함정+지름길, 추가 턴+시간 초과, 분신+골인(남은 말 없음), 왕좌 찬탈 차이 이전
- 타이머: `chooseThrow`(O-P8)는 시간 초과 시 무작위 선택 테스트 있음. 대상 선택은 화면 상태라 시간이 끝나면 서버가 기존 규칙대로 자동 던지기/이동하고 선택 패널은 닫힘
- 재접속: 대상 선택 중 새로고침하면 선택 중이던 대상은 사라지고(화면 상태) 카드를 다시 누르면 됨. 서버 상태(예약·남은 횟수·함정 등)는 유지
- 봇 완주 30판(2·3·4인, 액티브 무작위 사용, 서버 오류 0건)은 **전체 경우의 수를 보장하지 않음**. 무작위로 고른 증강·대상만 지나감
