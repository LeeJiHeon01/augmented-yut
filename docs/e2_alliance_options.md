# E2 임시 동맹 · 팀 증강 인원별 규칙 (확정)

작성: 2026-10-24 · 상태: **확정·구현 완료** — 1~10번 전부 A안 + 추가 규칙(새 팀 효과가 이전 효과 대체, 정상 턴·라운드 기준, 개인전 승리). 최종 규칙은 `progress.md` 확정 31·32번. 아래는 결정 당시 선택지 기록.

원문
- E2 임시 동맹: 무작위 2인씩 1라운드 팀으로 묶어 아군 잡기 차단. **개인전 승리 조건은 그대로**, 임시 잡기 금지만 적용 (v3 부록 B)
- C-G1 운명의 팀 교체(골드·액티브): 무작위 상대와 2턴 임시 팀, 서로 말 잡기 불가
- C-P2 대환장 팀 셔플(프리즘·대혼란): 4명 무작위 2:2 팀 편성, 2라운드 아군 잡기 불가·공동 승리 계산

## 1. 공통으로 정해야 할 것

| 항목 | 선택지 | 추천 |
|---|---|---|
| 아군 말이 같은 칸에 멈추면 | ① 공존(잡지 않음, 업지도 않음) ② 업힘(함께 이동) | ① — 소유가 섞이지 않아 승리 판정이 단순 |
| 아군 잡기를 노린 증강(강제 이동·전염병 등) | ① 증강은 아군도 잡음 ② 증강도 아군 잡기 금지 | ② — "아군 잡기 차단" 문구와 일치 |
| 승리 | ① 개인전 그대로(E2 원문) ② 팀원 중 한 명이 이기면 둘 다 승리(C-P2 원문 "공동 승리") | E2·C-G1 ①, C-P2 ② |
| 해제 시점 | 전원 정상 턴 1회(1라운드) 또는 2라운드 / 2턴 경과 | 원문 기간 그대로 |
| 해제 순간 같은 칸의 전 아군 | ① 계속 공존 ② 그 칸 다음 착지 때 잡기 판정 | ① |
| 화면 | 패널·말에 팀 표시, 대혼란 패널에 남은 라운드 | 기존 패널에 텍스트 배지만 추가(새 디자인 필요 시 별도 요청) |
