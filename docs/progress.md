### 대혼란 증강 확률 예시 (사용자 제시)

프리즘 10개 = 일반 9개 + 대혼란 1개, 대혼란 내부 확률 5%:

- 등급 내부: 대혼란 5%, 일반 각 (100 − 5) / 9 = **10.556%**
- 전체 기준(프리즘 20%): 대혼란 **1%**, 일반 각 **약 2.111%**
